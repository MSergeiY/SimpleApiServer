📄 Документация API (консольное приложение)

Базовый URL: http://localhost:5000 (или адрес вашего сервера)

Приложение реализует HTTP API для управления задачами с JWT-аутентификацией.

🔐 Аутентификация

POST /api/auth/register
Регистрация нового пользователя.
Тело (JSON): 
{
  "email": "user@example.com",
  "password": "yourpassword",
  "name": "Имя Пользователя"
}
POST /api/auth/login
Вход в систему. Возвращает JWT-токен.
Тело (JSON): 
{
  "email": "user@example.com",
  "password": "yourpassword"
}
Ответ: 
{
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "email": "user@example.com",
    "expiresAt": "2025-04-01T12:00:00Z"
  }
}

📋 Задачи (требуют JWT для POST)

GET /api/tasks
Получить список задач. Поддерживаются параметры фильтрации, сортировки и пагинации:
?isCompleted=true&priority=High&orderBy=createdAt&direction=desc&page=1&pageSize=5
POST /api/tasks (защищён JWT)
Создать новую задачу. Требуется заголовок: Authorization: Bearer <token>
Тело (JSON): 
{
  "title": "Купить продукты",
  "description": "Молоко, хлеб, яйца",
  "priority": 4,
  "dueDate": "2025-12-31T23:59:59Z"
}
priority от 1 (Low) до 5 (High).
GET /api/tasks/{id}
Получить задачу по ID.
PUT /api/tasks/{id}
Обновить задачу. Передаются любые поля из объекта задачи.
DELETE /api/tasks/{id}
Удалить задачу.

📦 Примеры запросов (curl)

Логин:

curl -X POST http://localhost:5000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","password":"123"}'

Создание задачи (с JWT):

curl -X POST http://localhost:5000/api/tasks \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <ваш_токен>" \
  -d '{"title":"Новая задача","priority":5}'
📌 Примечание: Документация размещена на GitHub Pages, а само API запускается локально или на сервере. Убедитесь, что базовый URL соответствует вашему серверу.
